🐧 eBPF Kernel Program

Tracepoints hook execve, openat, connect, mmap, setuid and LSM hooks intercept security-sensitive operations. Each event is packed into a 180-byte struct event_t with a UUID event_id for forensic linking. Submitted via lock-free ring buffer to userspace at rates up to 2.9M events/s.

🗺️ IPGBuilder — Algorithm 1 (Novel Contribution 1)

Converts the 20-event window into a directed multigraph: nodes are (comm, resource_type) pairs; edges are syscalls with dt_ms time deltas. Parallel edges with the same syscall label are merged (deduplication). Sensitive resources (/etc/shadow, SSH keys) are flagged with sensitive:true. Serialized to compact YAML — 64.1% token reduction vs raw strace (avg 1097→394 tokens at window=20). Structural entropy H(G) computed for tier selection in Algorithm 2.

sentinel/ipg.py · tiktoken cl100k_base · 86.7% reduction at full-trace
ipg_text (YAML) H(G) structural entropy sensitive: true edges
ipg_text + H → DualTierClassifier.classify(ipg_text, H)

🤖 DualTierClassifier — Algorithm 2 (Novel Contribution 2)

Draft tier (llama3.2:1b): if H(G) < high_threshold, send to fast 1B model. If response is BENIGN with conf ≥ 0.90 → accept (fast-path, 35.7% of cases skip 8B). If MALICIOUS → always escalate.

Full tier (llama3.1:8b): receives IPG + system prompt (MITRE ATT&CK expert persona) + few-shot examples + FreeBSD/Linux domain context. Returns structured JSON: label, confidence, mitre_ttps, evidence_refs[], chain_of_thought. Structured output enforced via format:"json" + Ollama. 3 retries with exponential backoff; falls back to MockClassifier on timeout.

✅ CoVeLoop — Chain of Verification (Novel Contribution 5)

4-step verification pipeline: Draft (initial decision) → Verify (cross-check each evidence_ref against the actual IPG) → Ground (EvidenceLinker: match evidence_refs[].event_desc against real eBPF event_id UUIDs in the window) → Synthesize (produce final decision with only verified evidence). Blocks hallucinated syscalls or resources that never appeared in the raw event stream. Forensic linking: verified_evidence_ids written to audit log.

🔒 LTL Symbolic Guardian (Novel Contribution 4)

Formal safety verification using 5 LTL axioms — two tiers:
Tier-1 RuntimeMonitor (O(1) per event): AX-1 nginx≠execve(/bin/bash), AX-3 prctl≠shadow_read, AX-4 ≠execve(/tmp/*), AX-5 setuid(0)→connect.
Tier-2 BüchiMonitor (AX-2): shadow_read ◇₁₀ connect — causal kill-chain detection over 10-event temporal window.
LTL violations can override LLM decision upward (floor): even a BENIGN LLM decision is escalated if AX-2 is violated.

sentinel/ltl.py · RuntimeMonitor · BüchiMonitor · SymbolicGuardian
violations: [AX-1…AX-5] severity: CRITICAL | HIGH ltl_floor confidence

⚡ CWAEEngine — Algorithm 3 (Novel Contribution 3)

Confidence-Weighted Adaptive Enforcement: maps final confidence to an enforcement tier. Optionally gated by EGTE (conformal calibration, Novel 6) for finite-sample over-escalation guarantee P(benign) ≤ α + 1/(n+1).

LOG_ONLY (<0.30): write to audit.jsonl.
PAUSE (0.30–0.50): SIGSTOP + operator alert.
KILL (0.50–0.70): SIGKILL + memory dump to results/logs/.
QUARANTINE (0.70–0.85): SIGKILL + XDP network block (BPF map).
ISOLATE (≥0.85): SIGKILL + XDP + cgroup freeze + incident report.
