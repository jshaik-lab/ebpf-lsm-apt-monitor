Moving Beyond Signatures to Intent

This report details the implementation of a novel security monitor. By capturing low-level system call sequences via eBPF and analyzing them locally with a quantized Large Language Model (Llama-3-8B-GGUF), the system identifies anomalous behaviors based on contextual intent rather than static heuristics.

🔍

Deep Visibility

eBPF hooks into the Linux kernel to trace execve, connect, and openat with near-zero overhead.

🧐

Contextual AI

Local LLM inference decodes the sequential relationship of syscalls to determine if an action constitutes a lateral movement, exfiltration, or normal operation.

🛡️

Zero Trust

Trained on datasets like DARPA Transparent Computing and Syzbot logs, the agent assumes breach and validates the intent of every process.
